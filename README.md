# Wave Radar — Drips Stellar Wave Live Sniper

Полуавтоматический радар для **Drips Stellar Wave** (без обхода капч/Turnstile):
1. Каждые **45 секунд** сканирует GitHub GraphQL и находит репозитории, где мейнтейнеры **прямо сейчас (за последние 15 минут) назначают задачи**.
2. Мгновенно подтягивает из `wave-api.drips.network` открытые задачи этих мейнтейнеров с **`200+ pts` и `0` заявок**.
3. Вытягивает из тела issue пути файлов и требования и генерирует готовый **английский pitch для 1-клик вставки**.
4. Контролирует твои **15/15 слотов**: сразу подсвечивает `ASSIGNED`, `LOST` и **зависшие (`STALE > 18h`)** заявки, которые пора отозвать.
5. Отдаёт удобный **локальный Web-дашборд** (`http://127.0.0.1:8787`) со звуковым оповещением, кнопками `Open Drips ↗` и `Copy Pitch`, а также умеет слать алерты в **Telegram**.

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --no-cache-dir -e ".[dev]"

cp .env.example .env
# Если установлен и авторизован `gh` CLI, GITHUB_TOKEN подхватится автоматически
```

### Запуск с Web-дашбордом

```bash
python -m wave_radar
# Откройте http://127.0.0.1:8787 в браузере
```

### Разовая проверка в консоли (`--once`)

```bash
python -m wave_radar --once
```
